# linux-bash-scripting
Linux and Bash scripting projects for DevOps automation


## 📂 Scripts

### Disk Usage Check
**File:** `disk-check.sh`

Checks the disk usage of the system using the `df -h` command.

### System Health Check
**File:** `system-health.sh`

Displays important system information including:

- Hostname
- Date and time
- Disk usage
- Memory usage
- System uptime

## 🛠️ Technologies Used

- Linux
- Bash Scripting

## 🚀 How to Run

```bash
chmod +x system-health.sh
./system-health.sh
